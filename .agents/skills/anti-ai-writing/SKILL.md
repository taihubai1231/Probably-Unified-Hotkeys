# 去除对外文案 AI 腔与人机味标准技能 (anti-ai-writing)

本技能为所有进入本工作区的智能代理在撰写、重构或审校面向玩家/用户的对外文案时的**必选操作规程**。

---

## 1. 核心定位与激活场景

在涉及以下任一文案的撰写、修改或评审时，必须执行本技能规程：
1. 模组根目录 `README.md` 及相关面向用户的引导文档；
2. Steam 创意工坊简介文件（`tools/steamcmd/probably_unified_hotkeys.vdf` 或相关发布描述）；
3. 游戏内展示的模组清单描述（`manifest.xml`）；
4. 版本更新历史（`CHANGELOG.md`）及 GitHub Release Notes；
5. 向用户/老板呈报的文案方案与修改对比。

---

## 2. 8 步去人机味与规范书面语执行清单 (Checklist)

在输出文案前，依次运行以下 8 项检查；凡命中任一违规项，必须在交付前就地改写：

### Check 1: 扫描并抹除高频 AI 词表与生造缩略词
全文检索并确保 100% 清除以下词汇：
- **夸张副词**：`彻底`、`全面`、`深度`、`大幅`、`完美`、`极致`、`丝滑`、`秒级`、`杜绝`、`斩获`。
- **公文与黑话**：`赋能`、`闭环`、`一站式`、`矩阵`、`抓手`、`颗粒度`、`旨在`、`致力于`、`重塑`、`构筑`、`格局`、`底座`。
- **生造缩略词与口语黑话（严禁造词，统一改为规范现代汉语书面语）**：`切场`（改为：返回主菜单/切换页面）、`退游`（改为：退出游戏）、`退页面`（改为：退出页面）、`开窗`（改为：打开页面/打开面板）、`换机`（改为：更换设备）、`秒开`（改为：缩短加载时间/快速显示）、`筛出`（改为：筛选出）。
- **机械承接**：`值得一提的是`、`毋庸置疑`、`不可否认`、`显而易见`、`与此同时`、`此外/同时/另一方面`（三连套话）。
- **处置方案**：删除空洞修饰词与生造缩略词，使用规范书面语直接陈述事实。

### Check 2: 拆解否定平行与虚假定义句
- 检查是否存在“不是……而是……”、“不仅是……更是……”、“并非仅仅……而是……”句式。
- **处置方案**：砍掉自问自答式的概念包装，直接讲清楚底层变动原因与玩家可感知的结果。

### Check 3: 消除「XX与YY」机械对称标题
- 检查所有层级的标题、列表大纲，杜绝清一色“A 与 B”的对称套路（如《机制与原理》、《安装与部署》、《冲突与检测》）。
- **处置方案**：按具体实质内容自然命名（如《功能说明》、《安装方法》、《冲突检测规则》）。

### Check 4: 剔除正文与列表中的括号补充癖
- 检查是否存在大量“（如……）”、“（支持……）”、“（包含……）”等打断阅读节奏的括号插入。
- **处置方案**：将举例融于主句（如“输入 chong 或 zhong 均可检索「多重」”），或直接删去无必要举例。

### Check 5: 破除机械列表模板与粗体滥用
- 严禁列表每一项都按 `* **词汇：** 解释句子` 的死板格式输出。
- **处置方案**：改用通顺自然的完整散文句，或平实列出项目要点，粗体仅用于极为关键的按键名或警告。

### Check 6: 斩断无争议防卫澄清与车轱辘话
- 删去所有前文无争议时的“但这并不意味着……”、“不能单凭此事认定……”、“仍须谨慎解读”。
- 删去文末毫无营养的“尽管面临挑战，未来依然可期……”式升华。
- **处置方案**：事实说完直接结束，不画大饼，不写空洞免责。

### Check 7: 审阅交付净版，严禁倾倒底层代码
- 向审阅者呈交预览时，禁止将带有 `[hr]`、`[b]`、`[list]` 的机器标记（如 Steam BBCode）直接贴在沟通正文中。
- **处置方案**：审阅统一使用排版干净的独立 Markdown 或纯文本净版文档；机器标记文本由发布工具写入底层 `.vdf` 文件。

### Check 8: 三端文案联动同步与轻量效率原则
- **三端联动排查**：修改任意一端（工坊 `.vdf`、GitHub `README.md`、游戏内 `manifest.xml`）的用词规范时，必须同步检查其余两端是否存在同类生造词或口径偏差，确保三端一致（组合键、鼠标右键/侧键与空键解绑保持同级并列；不提已弃用的多吉改键器与已删 FAQ）。
- **纯文本免跑重型编译**：仅修改文案文本时，只做字节数（VDF `< 8,000` UTF-8 字节）与引号/标签闭合核对，严禁重跑全模组编译与单测浪费时间。

## 3. 常见 AI 腔与真人作者改写对照表

| 场景 | ❌ 典型 AI 腔（人机味） | ✅ 真人作者改写（自然平实） |
|---|---|---|
| **功能开场** | 本模组旨在为广大玩家构筑全方位的一站式按键统一解决方案，全面赋能操作体验。 | 模组装多了改键繁琐、同键位冲突卡死？这个模组用来集中统一管理所有按键。 |
| **Bug 修复** | 彻底修复同主键组合键失效的严重痛点，全面杜绝误触，带来丝滑体验。 | 修复同主键组合键失效或单键误触发问题。 |
| **多音字支持** | 支持多音字模糊检索体系（如「多重」支持 chong / zhong 两种拼音命中）。 | 支持多音字检索，例如输入 chong 或 zhong 都能搜到「多重」。 |
| **章节标题** | 1. 架构与分层<br/>2. 性能与表现<br/>3. 冲突与排查 | 1. 模块设计<br/>2. 界面流畅度优化<br/>3. 按键冲突排查 |
| **列表排版** | * **兼容范围：** 深度适配多款工坊热门模组。<br/>* **保存机制：** 实现秒级安全落盘。 | 新增支持 11 款主流创意工坊模组。<br/>修改配置后自动即时保存至本地。 |

## 4. 门禁与违规判定

1. **红线阻断**：任何包含高频禁词、未展开 BBCode 源代码或八股句式的文案，严禁进入 `git commit` 或提交人类审阅。
2. **参考资产**：更详尽的成因剖析、学术引用与实战案例，参见工程手册 [docs/ANTI_AI_WRITING_GUIDE.md](file:///d:/Workspace/probably_unified_hotkeys_re/docs/ANTI_AI_WRITING_GUIDE.md)。
