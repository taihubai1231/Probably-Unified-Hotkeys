# 可能是按键统一优化 (Probably Unified Hotkeys)

《深空当铺》（*Probably Stolen*）的原版与工坊模组设置整合模组。沿用游戏原版 UI 样式，把分散在各处的模组快捷键与常规设置收进官方 `ESC → 选项` 页面，同时补齐组合键、鼠标右键/侧键、空键解绑、多音字搜索与界面/退游加速。

- **模组作者**：太湖白1231
- **当前版本**：`v1.5.0`
- **适用游戏版本**：《深空当铺》(`0.46` / `0.46D`)
- **Steam 创意工坊**：[物品 ID 3837828444](https://steamcommunity.com/sharedfiles/filedetails/?id=3837828444)
- **开源协议**：MIT License
- **玩家交流群**：`1127147529`

## 功能概览

- 原版设置在上、模组配置在下，按拼音首字母自动归类卡片，支持折叠与一键恢复默认。
- 支持 Shift / Ctrl / Alt 组合键、鼠标右键/中键/侧键（Mouse1~6）及空键解绑（按 Esc 设为「无」）；触发组合键时自动拦截同名单键误触。
- 搜索框支持简繁中文、多音字、全拼与首字母拼音，点击 `[!]` 可快速筛选发生冲突的键位。
- 展开本模组卡片提供 3 套本地方案预设（方案一/二/三）与剪贴板导入导出，方便多场景切换或换机迁移。
- 自动翻译常见模组配置名；未走官方标准接口的模组，可通过顶部「模组排查」一键复制配置汇总。
- 选项页面单帧响应，改造件模组封面直接从本地读取秒开，退出游戏与返回主菜单无需等待卡顿。

## 安装方法

### 方式一：Steam 创意工坊（推荐）
1. 在 Steam 创意工坊订阅 [可能是按键统一优化](https://steamcommunity.com/sharedfiles/filedetails/?id=3837828444)；
2. 启动游戏，在主菜单「改造件 (Mods)」中勾选启用本模组并重启游戏。

### 方式二：手动安装
下载 Release 压缩包，解压后将文件夹放入游戏根目录的 `Mods/probably_unified_hotkeys/` 路径下，确保目录内包含以下 4 个文件：
- `ProbablyUnifiedHotkeys.dll`
- `manifest.xml`
- `README.md`
- `preview.png`

> **提示**：本模组基于游戏内置的原生模组系统运行，不需要安装 BepInEx 等外部前置。默认以官方 0 权限纯净模式安全运行。

## 使用说明

1. 按 `ESC` 打开「选项」，点击按键框后直接按下新键位、组合键或鼠标按键即可录入；按 `Esc` 可清除为「无」，点击鼠标左键取消录入并还原。
2. 调整完毕后点击窗口底部的「应用」保存。未保存直接关闭时，系统会弹出确认框提示保存或放弃。
3. 展开本模组卡片，可通过「方案一 / 方案二 / 方案三」保存或读取不同键位方案，也可通过「导出剪贴板 / 导入剪贴板」跨设备转移配置。
4. 遇到未被正确收纳的第三方模组时，点击选项页顶部的「模组排查」→「一键复制排查汇总」，将信息反馈给开发者以便适配。

## 功能开关

可在「主菜单 → 改造件 → 本模组右侧齿轮」或「ESC → 选项 → 本模组卡片」中随时开关，即时生效：

| 功能开关 | 默认值 | 作用说明 |
|---|---|---|
| `界面语言 (ui_language)` | `auto` | 跟随游戏语言，也可手动指定为简体中文或英文 |
| `流畅度优化 (enable_performance_patches)` | `开启` | 开启单帧响应与本地封面秒开缓存，关闭后走游戏原版加载逻辑 |
| `加速退游与返回主菜单 (enable_fast_quit)` | `开启` | 缩短保存配置后退出游戏与返回主菜单的等待时间，避免切场卡顿 |
| `拼音与繁简搜索 (enable_pinyin_search)` | `开启` | 开启搜索栏的全拼、首字母缩写、多音字与繁简中文互搜 |
| `组合键防误触隔离 (enable_key_suppression)` | `开启` | 触发组合键时自动拦截同名单键，防止误触单键 |
| `详细调试日志 (enable_debug_logging)` | `关闭` | 在运行日志中输出详细排查信息，默认关闭，排查适配问题时开启 |

## 存档说明

本模组只读写本地配置，不往游戏存档里写任何数据，中途加装或移除都不会影响已有存档。卸载时在主菜单「改造件」里取消勾选，或直接删掉模组文件夹即可，键位会自动恢复原版默认。

## 模组作者接入

如果你是《深空当铺》的模组作者，按官方标准编写配置即可自动被本模组收纳与汉化，无需额外引用本模组的 DLL：

1. 通过游戏官方 `ModConfig` 接口注册配置项，按键类型建议声明为 `KeyCode`。
2. 通过官方 `Localization` 接口为配置项提供中文与英文译文，本模组会自动读取并在界面展示。
3. 本模组会自动读取标准配置项并按拼音首字母排好，无需配置任何额外依赖。
