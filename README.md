# 可能是按键统一优化 (Probably Unified Hotkeys) v1.3.0

> 一站式统一按键与模组配置中心 —— 支持 `Shift / Ctrl / Alt` 组合键与鼠标侧键（`Mouse3~Mouse6`）、全局防重复隔离、空键解绑与冲突智能排查。

---

## 🌟 核心特性概览

### 1. 深度原生融合与全局防重复隔离
- **无缝嵌入官方选项页**：直接集成于游戏原生 ESC「选项」界面，保持原生视觉交互习惯，告别杂乱外挂弹窗。
- **全自动过滤上方模组重复项**：基于 `GameOptionRegistry` 注册来源与程序集签名智能识别，所有第三方模组配置自动统一收纳至下方「模组配置中心」，彻底消除上下重复。

### 2. `Shift / Ctrl / Alt` 组合键与鼠标组合（v1.3.0 新增）
- **原版与全模组通用组合键**：同时在上方原版键位、下方模组卡片（`ModConfig`、`GameOptionRegistry`、`Pen便利性优化`、`物品名称常显`、`冲突扫描器`、`势力声望扩展`、`客户需求高亮` 等）及 `[!] 仅看冲突` 视图中完整支持 `Shift`、`Ctrl`、`Alt` 单修饰或多重组合键（如 `Ctrl + E`、`Ctrl + Shift + F`）。
- **原生风格鼠标组合键与单修饰键**：按住修饰键再点击左键/右键/中键可绑定 `Alt + 左键`、`Ctrl + 右键` 等操作；直接点按并松开单个修饰键则保持单独修饰键绑定（兼容原版 `LeftAlt`/`LeftControl` 等快速操作）。
- **智能不互串的冲突检测与触发抑制**：`Ctrl + F` 与单独 `F` 不再误报冲突；实际按键触发时，按下组合键仅触发对应组合动作并精准抑制裸键误触，不按其余修饰键的普通热键不受干扰。

### 3. 鼠标侧键完整支持（v1.3.0 新增）
- **全面兼容 `Mouse3 ~ Mouse6`（`鼠标侧键1 ~ 4`）**：独立轮询鼠标侧键输入并绕过 Unity `Input.anyKeyDown` 漏检限制，支持单独绑定及 `Shift / Ctrl / Alt + 鼠标侧键1~4` 组合，且在原版、模组卡片、捕获界面与运行时热键检查中全部显示中文友好名称并正常生效。

### 4. 垂直分区分段卡片与统一视觉交互
- **规整折叠卡片**：`34×34` 方形折叠按钮（`▶`/`▼`），展开卡片后**上半截集中展示快捷键、下半截展示常规设置**（开关/滑块/下拉框），配有完整分割线与左缩进排版。
- **展开按需显示 `[ 恢复 ]`**：折叠时隐藏重置按钮避免拥挤；展开后显示并支持所有卡片（含无显式默认值的模组启动快照恢复）。
- **统一按键状态色调**：未绑定显示原生 `无` 并统一为柔和灰，已绑定保持原版一致色，真实组合键位冲突显示为淡橙色（`#ffb347`）并配橙色 `[!]` 悬浮详单。

### 5. 四模式顶部搜索与顺手的 `Esc` 解绑
- **两行舒展顶部工具栏**：搜索范围支持切换 `整体搜索` / `按键+常规` / `仅搜按键` / `仅搜常规`，内置 20,902 字 CJK 拼音搜索引擎（支持中英文、组合键前缀如 `ctrl`/`侧键` 与拼音首字母缩写）。
- **直观解绑**：按 **`Esc`**（不关闭设置窗口）立即解绑为空（`无`）；**`Backspace`（退格）与 `Delete` 键均保留为正常可绑定快捷键**。

### 6. 统一规范命名、0 掉帧缓存与官方安全全绿
- **工程与目录全统一**：`probably_unified_hotkeys` / `ProbablyUnifiedHotkeys.dll` / `可能是按键统一优化`。
- **0 掉帧指纹缓存**：基于模组与注册表指纹的轻量级缓存，日常开关设置毫秒级响应，无损卸载，且通过官方 `ModScanner` 静态扫描零告警。

## 🎮 使用方法

1. 安装本模组后进入游戏，按 **ESC** 打开 **「选项」**。
2. 顶部可切换搜索范围并用中英文/拼音检索，或点击 **`[!] 仅看冲突`** 集中排查重复键位。
3. 滚动至下方模组配置中心展开卡片即可调整热键与常规设置，展开卡片右上角可点击 **`恢复`**。
4. 点击任意按键按钮后：
   - 直接按单键或鼠标中键/侧键1~4，或按住 **`Shift` / `Ctrl` / `Alt`** 再按主按键 / 鼠标左右键 / 侧键即可绑定组合键；
   - 按 **`Esc`** 解除绑定（`无`）；`Backspace` / `Delete` 可直接绑定；单击左键/右键取消本次输入；
   - 完成后点击底部 **「应用设置」** 持久化保存。
