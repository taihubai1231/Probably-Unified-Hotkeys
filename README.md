# 允许绑定空按键 (Allow Unbind Key) v1.1.0

深空当铺 (*Probably Stolen*) 官方规范原生模组。

## 功能介绍
1. **全入口支持清空/解绑按键**：
   - **游戏原生按键设置**：进入「选项 -> 按键设置」，点击目标项等待输入时按下 **Backspace（退格键）** 或 **Delete 键**，即可设为“无 / None”。
   - **多吉改键器（Duoji Hotkey Manager）**：在多吉改键器面板中点击任意模组的按键按钮，按下 **Backspace** 或 **Delete** 即可将其清空为“None（无）”，且改键器已完美兼容显示与保存未绑定的热键。
   - **各类工坊模组自带设置界面**：全面兼容快捷键冲突扫描（ConflictScanner）、物品名称常显（ShowItemNames）、智能物品整理（SmartInventoryArrange）、势力声望拓展（FactionReputationExpansion）、修改器（TrainerUI）等主流模组的独立按键捕获面板。
2. **修复冲突误报**：原版游戏在检测按键冲突时未排除 `KeyCode.None`，会导致多个空按键并存时提示冲突无法保存。本模组彻底修复了这一逻辑，所有未绑定的动作均可和谐共存。
3. **动态无缝加载**：采用解耦的动态装载设计，无论模组的加载顺序如何、是否安装了其他特定模组，都不会产生依赖报错，纯净安全。
4. **通过官方 ModScanner 安全扫描**：符合官方模组安全与权限规范，0 风险标志，0 额外权限需求，不影响游戏原生存档和联机。

## 适用游戏版本
- 0.46 / 0.46D 及后续版本
