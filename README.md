# 可能是按键统一优化 (Probably Unified Hotkeys)

《深空当铺》（*Probably Stolen*）的原版与创意工坊模组设置整合模组。沿用游戏原版 UI 样式，将分散在各处的模组快捷键与常规设置统一纳入官方 `ESC → 选项` 页面，支持组合键、鼠标右键/侧键绑定、空键解绑与多音字检索，并对选项页面、模组封面加载及退出游戏速度进行了优化。

- **模组作者**：太湖白1231
- **当前版本**：`v1.5.1`
- **适用游戏版本**：《深空当铺》(`0.46` / `0.46D`)
- **Steam 创意工坊**：[物品 ID 3837828444](https://steamcommunity.com/sharedfiles/filedetails/?id=3837828444)
- **开源协议**：MIT License
- **玩家交流群**：`1127147529`

## 功能概览

- 提供三种显示形态：支持模组界面合并至原版界面、模组独立界面在原版选项页左下角放置模组设置入口，以及切换为原版设置界面仅从改造件页面齿轮打开模组配置。
- 原版设置位于上方，创意工坊模组配置默认按拼音首字母排列于下方；各分区均支持独立折叠与恢复默认设置。
- 按住模组卡片右侧拖动手柄即可上下移动卡片，提供按名称升序、按名称降序、自由拖动排列、最近启用优先、按键数量优先与游戏加载顺序 6 种排序方式，排布顺序随预设方案保存且不受恢复默认影响。
- 支持 Shift / Ctrl / Alt 组合键、鼠标右键/中键/侧键绑定及空键解绑；触发组合键时自动屏蔽同名单键，避免误触。
- 支持简繁中文、英文、多音字及拼音全拼/首字母检索；点击 `[!]` 可筛选出全部冲突键位集中修改。
- 内置 3 套本地预设槽位并支持剪贴板导入导出，快捷键与卡片排布顺序均可随方案备份与恢复，便于切换不同键位方案或跨设备迁移配置。
- 在改造件齿轮页与本模组卡片内划分 7 大设置分区，支持单独调整工具栏各项控件显隐、打字停顿响应延时、按键录入与冲突规则、界面语言及各项加速开关，所有设置即时生效。
- 自动汉化常见模组的英文分类与配置项名称；支持将特殊配置项手动设为按键绑定，并提供「模组排查」复制汇总信息以便反馈适配。
- 优化选项页面打开速度，改造件页面优先读取本地模组封面并补充云端封面缓存，缩短返回主菜单与退出游戏的等待时间。
- 对第三方动态本地化与配置异常增加受控隔离保护，单个模组异常不再导致整组选项报错或回退原版。

## 安装方法

### 方式一：Steam 创意工坊（推荐）
1. 在 Steam 创意工坊订阅 [可能是按键统一优化](https://steamcommunity.com/sharedfiles/filedetails/?id=3837828444)；
2. 启动游戏，在主菜单「改造件 (Mods)」中勾选启用本模组并重启游戏。

### 方式二：手动安装
下载 Release 压缩包，解压后将文件夹放入游戏根目录的 `Mods/probably_unified_hotkeys/` 路径下，确保目录内包含以下 4 个文件：
- `ProbablyUnifiedHotkeys.dll`
- `manifest.xml`
- `README.md`
- `preview.png`

> **提示**：本模组基于游戏内置的原生模组系统运行，无需安装 BepInEx 等外部前置工具，默认以官方零权限标准安全运行。

## 使用说明

1. 按 `ESC` 打开「选项」，若选用模组独立界面则点击原版选项页左下角「模组设置」入口；点击目标按键槽后直接按下新按键、组合键或鼠标右键/中键/侧键即可完成绑定；录制状态下按 `Esc` 可清空为「无」，单击鼠标左键则取消本次录入并保留原键位。
2. 修改完成后点击窗口底部的「应用」保存生效。未保存直接关闭窗口时，系统会弹出确认框提示保存或放弃修改。
3. 按住卡片右侧拖动手柄可上下移动卡片，也可在顶栏下拉框切换排序方式；展开本模组卡片，可通过「方案一 / 方案二 / 方案三」保存或读取不同键位与卡片顺序方案，也可通过「导出剪贴板 / 导入剪贴板」跨设备迁移配置。
4. 遇到未走官方配置接口的第三方模组时，可点击选项页顶部的「模组排查」→「复制排查汇总」，将信息反馈给开发者以便跟进适配。

## 功能设置

可在「主菜单 → 改造件 → 本模组右侧齿轮」或「ESC → 选项 → 本模组卡片」中随时调整，即时生效：

| 设置分组 | 包含设置项 | 默认值 | 作用说明 |
|---|---|---|---|
| **语言设置** | 界面语言 | `跟随游戏语言` | 跟随游戏语言，也可手动指定为简体中文或英文 |
| **选项页面布局** | 选项页面显示位置、允许拖动卡片自由排序、显示卡片排序下拉框、显示方案预设卡片、未保存修改退出确认弹窗 | `开启，显示位置默认为合并` | 调整模组界面显示形态，支持拖动卡片自由排序，并提供方案预设与防误退弹窗 |
| **选项页顶部工具栏** | 搜索框、搜索范围、打字停顿搜索、停顿等待毫秒数、内容筛选、仅看冲突按钮、模组排查按钮、展开收起按钮、按键提示 | `开启，默认等待 300 毫秒` | 自定义工具栏各项控件显隐，并可调整输入停顿等待时间 |
| **快捷键绑定规则** | 允许绑定组合键、允许绑定鼠标键、允许绑定空键、允许冲突按键同时生效 | `开启` | 控制是否允许绑定组合键、鼠标侧键或右键、按 Esc 解绑，以及相同按键是否在不同模组同时触发 |
| **改造件页面设置** | 隐藏本模组封面大图、加快改造件列表加载、优先加载本地模组封面图、跳过冲突检测器重复扫描 | `开启` | 优化改造件面板排版布局，优先读取本地模组封面并消除重复扫描 |
| **预载及退出加速** | 在主菜单提前加载设置数据、后台提前生成折叠卡片内容、跳过返回主菜单等待时间、加快退出游戏关闭速度 | `开启` | 缩短选项面板响应与图片载入时间，消除返回主菜单与退出游戏时的多余等待 |
| **调试日志** | 输出控制台调试日志 | `关闭` | 在运行日志中输出详细排查信息，仅在排查适配问题时开启 |

## 存档说明

本模组仅读写本地配置文件，不向游戏存档写入任何数据，中途启用、停用或移除均不影响现有存档。卸载时在主菜单「改造件」中取消勾选，或直接删除模组文件夹即可，键位将自动恢复为原版默认设置。

## 模组作者接入

如果你是《深空当铺》的模组作者，按官方标准编写配置即可自动被本模组收纳与汉化，无需额外引用本模组的程序集：

1. 通过游戏官方 `ModConfig` 接口注册配置项，按键类型建议声明为 `KeyCode`。
2. 通过官方 `Localization` 接口为配置项提供中文与英文译文，本模组会自动读取并在界面展示。
3. 本模组会自动识别标准配置项并按拼音首字母排序展示，无需添加任何额外依赖。
