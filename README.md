# 可能是按键统一优化 (Probably Unified Hotkeys)

将《深空当铺》（*Probably Stolen*）原版与所有创意工坊模组的快捷键、常规设置合并至官方 `ESC → 选项` 页面，保持原版原生界面风格，解决多模组改键分散与界面卡顿问题。

- **模组作者**：太湖白1231
- **当前版本**：`v1.5.0`
- **适用游戏版本**：《深空当铺》(`0.46` / `0.46D`)
- **Steam 创意工坊**：[物品 ID 3837828444](https://steamcommunity.com/sharedfiles/filedetails/?id=3837828444)
- **开源协议**：MIT License
- **玩家交流与反馈群**：`1127147529`

## 主要功能

- **统一设置面板**：在原版「选项」页上方显示原生设置与键位，下方按拼音首字母展示各模组设置卡片。
- **组合键与鼠标侧键**：支持 Shift、Ctrl、Alt 组合键与鼠标侧键（Mouse3~Mouse6）；按下组合键时自动抑制单键冲突。
- **快速检索与冲突筛选**：支持拼音首字母、全拼与中英双语搜索；点击 `[!]` 可仅查看发生键位冲突的项目并直接修改。
- **3 套方案预设与剪贴板备份**：支持在 3 套本地配置方案之间快速切换，并可通过剪贴板文本一键导出或导入分享键位。
- **模组配置整理与疑难排查**：自动将常见模组的配置标题翻译为中文；对特殊键位支持一键「设为按键绑定」或「忽略」。
- **界面流畅度与秒退优化**：大幅降低模组较多时的卡顿与内存波动，并在保存设置后优化退出游戏的响应速度。

## 安装与使用

### 方式一：Steam 创意工坊（推荐）
1. 在 Steam 创意工坊订阅 [可能是按键统一优化](https://steamcommunity.com/sharedfiles/filedetails/?id=3837828444)；
2. 启动游戏，在主菜单「改造件 (Mods)」中勾选启用本模组并重启游戏即可。

### 方式二：手动安装
下载 Release 压缩包，解压后将文件夹放入游戏根目录的 `Mods/probably_unified_hotkeys/` 路径下，确保目录内包含以下 4 个文件：
- `ProbablyUnifiedHotkeys.dll`
- `manifest.xml`
- `README.md`
- `preview.png`

> **提示**：本模组基于游戏内置的原生模组系统运行，不需要安装 BepInEx 等任何外部前置工具。

## 快速上手与操作说明

1. **修改按键**：按 `ESC` 打开「选项」，点击目标按键按钮开始录制；按下想要绑定的按键或组合键即可完成绑定。
2. **清除按键**：录制按键时按下 `Esc` 键，可将按键绑定清除为「无」。
3. **取消录制**：在录制状态下鼠标左键或右键点击空白处，即可取消当前录制并保留原键位。
4. **保存设置**：修改完成后，点击窗口底部中央的「应用」按钮保存生效。
5. **未保存提醒**：若修改了设置未点保存直接关闭窗口，会弹出原生确认框提示保存或放弃修改。

## 功能开关说明

模组内置了多项实用功能开关。可在「主菜单 → 改造件 → 本模组右侧齿轮」或「ESC → 选项 → 本模组卡片」中随时开关，即时生效：

| 功能开关名称 | 默认值 | 作用说明 |
|---|---|---|
| `界面语言 (ui_language)` | `auto` | 界面语言跟随游戏语言，亦可手动切换为简体中文或英文 |
| `流畅度深度优化 (enable_performance_patches)` | `开启` | 优化开窗装配与改造件列表渲染，降低卡顿与内存波动 |
| `极速秒退游戏 (enable_fast_quit)` | `开启` | 保存配置后优化退出游戏响应速度，避免退出时卡死假死 |
| `智能拼音与繁简检索 (enable_pinyin_search)` | `开启` | 支持拼音全拼、首字母缩写与繁简中文互搜 |
| `组合键防误触隔离 (enable_key_suppression)` | `开启` | 触发组合键时自动拦截同名单键，防止误触 |
| `详细调试日志 (enable_debug_logging)` | `关闭` | 在运行日志中输出详细的适配排查信息，日常建议关闭 |

## 存档兼容性与卸载

- **兼容性**：100% 兼容现有存档。本模组仅管理界面显示与键位映射，不向游戏存档文件写入任何数据，随时可加可删。
- **卸载**：直接在「改造件」菜单中取消勾选或删除本模组目录即可，游戏将自动恢复为原版默认按键设置。

## 面向其他模组作者的对接说明

如果你是《深空当铺》的模组开发者，希望你的模组设置与按键被本模组良好收纳并自动中文化，建议遵循以下官方标准做法：

1. **配置注册**：通过游戏官方提供的 `ModConfig` 接口注册配置项，按键类型建议声明为 `KeyCode`。
2. **标题与本地化**：通过官方 `Localization` 接口为配置项提供中文与英文译文。本模组会自动读取并在界面中正确展示。
3. **免侵入适配**：本模组会自动识别标准注册的模组并按拼音首字母收纳，无需对本模组添加任何依赖引用。
