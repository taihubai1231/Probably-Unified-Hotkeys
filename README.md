# 深空当铺：可能是按键统一优化 (Probably Unified Hotkeys & Settings) v1.2.0

> 一站式统一按键管理与模组配置中心 —— 彻底解决官方原生改键检测不全、多吉改键器漏检、设置空键后选项消失等历史顽疾！

---

## 🌟 核心特性概览

### 1. 深度原生融合，统一设置中心
- **无缝嵌入官方选项页**：直接集成于游戏原生的 ESC「选项」界面，采用与原版完全一致的 UI 风格与交互动效，告别杂乱外挂弹窗。
- **清晰层级划分**：
  - **优先展示官方原版**：原版的「游戏」、「音频」、「画面」、「对话」及「原版键位」完好保留在页面最上方。
  - **模组配置中心在后**：原版下方整齐呈现所有已加载模组的独立配置卡片，默认按拼音（A-Z）规范排序。

### 2. 垂直分区分段卡片（Scheme 1）
- 每个模组卡片均支持一键**折叠 / 展开**，加载几十个模组也能保持整洁清爽。
- 展开卡片后采用直观的垂直分区：
  - **上半截：通用常规设置**（布尔开关 Toggle、数值滑块 Slider、下拉菜单 Dropdown）。
  - **下半截：快捷键绑定**（按键按钮、键位名称、解绑说明）。
  - 附带单模组专属的 **[ 恢复默认 ]** 按钮，一键安全回退。

### 3. 顶部固定快捷控制条
- 页面上方常驻便捷工具栏，不受页面滚动影响：
  - **实时拼音/中英文检索**：内置 20,902 字 CJK 高性能纯内存拼音检索引擎，支持**中文全称、英文、全拼及拼音首字母缩写**（例如输入 `sp` 即可瞬间定位 `商品` 相关设置）。
  - **[ ⚠ 仅看冲突 ] 切换按钮**：点击即进入冲突专属聚合视图，仅展示发生冲突的键位，并按按键分类罗列所有冲突项。
  - **[ ⊞ 全部展开 / 收起 ] 按钮**：一秒切换所有模组卡片的折叠状态。

### 4. 优雅的冲突预警体系
- **淡橙色（#ffb347）提示**：发生按键冲突时以淡橙色文字温和预警，避免原版刺眼的红字干扰。
- **悬浮详尽诊断**：鼠标悬停于冲突键位上时，浮动展示冲突来源列表（如：`冲突提示: 与 [势力声望]、[物品常显] 存在键位冲突`）。
- **尊重玩家自由**：冲突仅作为友好提示，绝不霸道阻断玩家保存或改为空键。

### 5. 坚固的空键解绑功能（Backspace / Delete）
- 在任何官方或模组按键捕获状态下，按下 **Backspace（退格键）** 或 **Delete 键**，即可将按键彻底解绑并设为 **[ 无 / None ]**。
- 彻底修复原版将 `KeyCode.None` 误判为冲突无法保存的官方 Bug，以及多吉改键器设置空键后配置项直接消失的重大缺陷。

### 6. 模组全覆盖与 0 卡顿指纹缓存
- **多引擎全覆盖识别**：
  - 自动识别官方 `ModConfig` 注册项；
  - 自动聚合扫描通过官方 `GameOptionRegistry` / `ModHelper` 注册的模组（如现实时钟等）；
  - 内置主流非标独立配置模组的专属无损适配器（物品名称常显、冲突扫描器、势力声望、客户需求高亮、Pen便利性优化、智能物品整理等）。
- **环境指纹极速缓存**：在游戏启动与模组装载完毕时完成指纹计算与索引扫描，游戏进行中按 ESC 呼出选项页面 **0 掉帧、0 额外卡顿**。

### 7. 极致安全与无损卸载
- **0 冗余留存**：不在游戏目录下残留任何私有不可逆数据库，卸载模组后通过原版原生生命周期无缝归位。
- **官方 ModScanner 全绿通过**：通过游戏官方 AST 严格安全静态扫描，**0 Findings（0 违规发现）、0 Capabilities（0 敏感权限需求）、0 HardFlags（0 拦截标识）、Refused: False**。

## 🎮 使用方法

1. 安装本模组后启动游戏，在主菜单或游戏局内按下 **ESC**，点击 **「选项」**。
2. 页面顶部将出现搜索栏及控制按钮：
   - 在搜索框内直接打字（如输入 `快速`、`kuai` 或 `ks`）实时过滤。
   - 点击 **[ ⚠ 仅看冲突 ]** 快速排查撞车按键。
   - 点击 **[ ⊞ 全部展开/收起 ]** 快速浏览。
3. 滚动至页面下方即可查看各模组卡片，点击任意按键后按下想要绑定的按键；若要清空按键，按下键盘上的 **Backspace（退格）** 或 **Delete** 即可设为空键。
4. 修改完成后点击底部的 **「应用设置」** 即可生效。
