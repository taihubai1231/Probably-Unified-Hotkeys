# 可能是按键统一优化 (Probably Unified Hotkeys)

模组越装越多，改键入口却散落各处——空键、组合键与鼠标侧键无处可设，按键冲突难以排查，就连打开「选项」「改造件」或「退出游戏」都时常卡顿？换电脑、多套玩法或者重装游戏后，几十个快捷键与杂项设置还要逐个重新调整？

这是专为《深空当铺 (Probably Stolen)》打造的一站式原生按键统一与流畅度优化模组：沿用游戏原版赛博 UI 画风与原生组件手感，不额外挂悬浮窗。按 `ESC → 选项`，即可在同一个页面里改键、管理原版与全部模组设置并切换预设。

## 功能概览

- **统一设置面板**：在原版「选项」页上方显示原生设置与键位，下方按拼音首字母归纳各模组配置卡片，支持分类折叠与一键恢复默认。
- **组合键、鼠标右键/侧键与空键绑定**：支持 `Shift / Ctrl / Alt` 组合键、鼠标右键/中键/侧键（`Mouse1 ~ Mouse6`）以及空键解绑（按 `Esc` 设为「无」）；触发组合键时自动抑制单键误触。
- **多音字搜索与冲突排查**：支持简繁中文、多音字、全拼/首字母拼音与英文检索，配合输入防抖流畅不卡顿；点击 `[!]` 可仅查看发生键位冲突的项目并集中改绑。
- **3 套方案预设与剪贴板备份**：展开本模组设置卡片，内置「方案一 / 方案二 / 方案三」3 套本地预设槽位（支持保存、读取、清空），支持「导出 / 导入剪贴板」快速迁移与备份。
- **模组配置整理与疑难排查**：自动将常见模组的配置标题翻译为中文；对特殊键位支持设为按键绑定或忽略；点击顶部「模组排查」→「一键复制排查汇总」可快速复制未走官方协议的第三方模组配置信息。
- **流畅响应与切场加速**：选项页面与「全部展开」单帧响应；改造件模组封面本地直接秒开，缩短退出游戏与返回主菜单的等待时间。

## 安装方法

### 方式一：Steam 创意工坊（推荐）
1. 在 Steam 创意工坊订阅 [可能是按键统一优化](https://steamcommunity.com/sharedfiles/filedetails/?id=3837828444)；
2. 启动游戏，在主菜单「改造件 (Mods)」中勾选启用本模组并重启游戏。

### 方式二：手动安装
下载 Release 压缩包，解压后将文件夹放入游戏根目录的 `Mods/probably_unified_hotkeys/` 路径下，确保目录内包含以下 4 个文件：
- `ProbablyUnifiedHotkeys.dll`
- `manifest.xml`
- `README.md`
- `preview.png`

> **提示**：本模组基于游戏内置的原生模组系统运行，不需要安装 BepInEx 等外部前置。默认以官方 0 权限纯净模式安全运行。

## 使用说明

1. **修改按键**：按 `ESC` 打开「选项」，点击目标按键卡槽开始录制；按下想要绑定的按键、组合键、鼠标右键/中键或鼠标侧键即可完成绑定。
2. **清除按键（空键解绑）**：录制按键时按下 `Esc` 键，可将按键绑定清除为「无」。
3. **取消录制**：在录制状态下单击鼠标左键，取消当前录制并保留原键位。
4. **保存设置**：修改完成后，点击窗口底部中央的「应用」按钮保存生效。若修改了设置未保存直接关闭窗口，会弹出原生确认框提示保存或放弃修改。
5. **方案预设与备份**：展开本模组设置卡片，可通过「方案一 / 方案二 / 方案三」保存或读取不同场景的键位配置；点击「导出剪贴板」可复制配置文本，点击「导入剪贴板」可跨设备快速还原。
6. **模组排查**：若部分工坊模组未走官方标准配置协议，可点击选项页顶部的「模组排查」→「一键复制排查汇总」，将信息反馈给开发者以便适配。

## 功能开关

可在「主菜单 → 改造件 → 本模组右侧齿轮」或「ESC → 选项 → 本模组卡片」中随时开关，即时生效：

| 功能开关 | 默认值 | 作用说明 |
|---|---|---|
| `界面语言 (ui_language)` | `auto` | 界面语言跟随游戏语言，也可手动切换为简体中文或英文 |
| `流畅度优化 (enable_performance_patches)` | `开启` | 开启单帧响应与本地封面秒开缓存，关闭后走游戏原版加载逻辑 |
| `加速退游与返回主菜单 (enable_fast_quit)` | `开启` | 缩短保存配置后退出游戏与返回主菜单的等待时间，避免切场卡顿 |
| `智能拼音与繁简检索 (enable_pinyin_search)` | `开启` | 开启搜索栏的拼音全拼、首字母缩写、多音字与繁简中文互搜 |
| `组合键防误触隔离 (enable_key_suppression)` | `开启` | 触发组合键时自动拦截同名单键，防止误触单键 |
| `详细调试日志 (enable_debug_logging)` | `关闭` | 在运行日志中输出详细排查信息，日常建议关闭 |

## 存档说明

- **存档安全**：不修改游戏存档。本模组仅管理界面显示与键位映射，不向游戏存档写入任何数据，随时可加可删。
- **卸载还原**：直接在「改造件」菜单中取消勾选或删除本模组目录即可，游戏自动恢复为原版设置。

## 模组作者接入

如果你是《深空当铺》的模组开发者，希望你的模组设置与按键被本模组自动收纳与汉化，遵循官方标准做法即可：

1. **配置注册**：通过游戏官方 `ModConfig` 接口注册配置项，按键类型建议声明为 `KeyCode`。
2. **标题与本地化**：通过官方 `Localization` 接口为配置项提供中文与英文文本，本模组会自动读取并在界面展示。
3. **无依赖识别**：本模组会自动识别标准注册的模组并按拼音首字母排序收纳，无需对本模组添加任何项目依赖。
