## 一、 主菜单冷启动与生命周期自检 (Cold Start & Lifecycle)
- [ ] **1.1 主菜单零 NRE 启动**：
  - 前置条件：安装最新构建的模组文件。
  - 操作步骤：启动游戏进程，观察进入主菜单的完整生命周期。
  - 预期结果：正常进入主菜单背景与主界面，无闪退（Zero CTD），查看 `%USERPROFILE%\AppData\LocalLow\ProbablyStolen\Player.log`，无 `NullReferenceException` 报错。
- [ ] **1.2 改造件齿轮选项配置**：
  - 操作步骤：点击主菜单「改造件 (Mods)」-> 找到本模组 -> 点击右侧齿轮图标。
  - 预期结果：弹出官方 `ModConfigWindow`，中文/英文字体正常，7 大功能开关正常展示且能即时修改。
- [ ] **1.3 主菜单直接按 Esc 响应性**：
  - 操作步骤：在主菜单界面多次按下键盘 `Esc` 键。
  - 预期结果：界面不会假死冻结，退出弹窗或默认行为正常响应。

## 三、 按键/组合键/侧键录入与 Esc 解绑 (Key & Combo Capture)
- [ ] **3.1 常见组合键录制与生效**：
  - 操作步骤：展开任意模组卡片，点击录入按钮（显示 `请按键... (Esc=无)`），依次测试 `Ctrl + C`、`Shift + Alt + F`、`Ctrl + Space`。
  - 预期结果：按钮上正确显示组合键文本；进入游戏后按下对应组合键，功能正常触发。
- [ ] **3.2 鼠标侧键与特殊键录入**：
  - 操作步骤：在录键状态下，点击鼠标侧键 `Mouse3`（侧键1）、`Mouse4`（侧键2）、`Mouse5`、`Mouse6`。
  - 预期结果：键位能正常捕获并格式化显示为 `鼠标侧键1~4`，局内触发一致。
- [ ] **3.3 Esc 键清空解绑为「无」与防误关窗**：
  - 操作步骤：在录键状态下按下键盘 `Esc` 键。
  - 预期结果：目标快捷键被解绑清空为 `无`（`KeyCode.None`），**当帧绝对不误触发退出弹窗，且选项窗口保持打开状态**。
- [ ] **3.4 组合键精确抑键与防误触隔离**：
  - 前置条件：绑定了 `Ctrl + C`，原版单键 `C` 绑定了状态面板。
  - 操作步骤：按下 `Ctrl + C`，观察游戏响应；再松开 Ctrl 单独按下 `C`。
  - 预期结果：按下 `Ctrl + C` 时，仅触发组合键功能，原版单键 `C` 被精确抑制（不打开状态面板）；单独按 `C` 时正常打开面板。
- [ ] **3.5 鼠标按键录入与左键取消契约 (ADR-010)**：
  - 操作步骤：
    1. 点击录入按钮进入录键状态，无修饰单击鼠标左键：立即取消本次录制并恢复原键位；
    2. 再次点击录入按钮，无修饰按下鼠标右键：直接录入并绑定为 `鼠标右键`（`KeyCode.Mouse1`），且等待鼠标右键松开后安全完成，严禁误触发取消；
    3. 测试按下 `Ctrl + 鼠标右键` 或 `Alt + 鼠标左键`：正确绑定为对应组合键；
    4. 测试按下鼠标中键：正确绑定为 `鼠标中键`（`KeyCode.Mouse2`）。

## 四、 `KeyCode.None` 零假脏弹窗与退出防丢保护 (Dirty State & Confirmation)
- [ ] **4.1 核心修复验证：解绑为无点击应用后退出**：
  - 操作步骤：将任意快捷键解绑为 `无`，点击底部的「应用」按钮保存；保存完成后按 `Esc` 或点右上角 `X`。
  - 预期结果：**直接平滑退出选项窗口，绝对不弹出「检测到未保存的更改」假脏弹窗**。
- [ ] **4.2 真实未保存修改拦截与三项选择**：
  - 操作步骤：修改任意原生滑动条或改动某按键（未点击应用），直接按 `Esc`。
  - 预期结果：正中央弹出原生样式的确认弹窗，展示「保存并退出」、「放弃修改」、「取消」三个按钮。
- [ ] **4.3 确认弹窗三大动作验证**：
  - 点击「取消」：弹窗关闭，停留在当前选项界面，修改内容保留；
  - 点击「放弃修改」：弹窗关闭，选项窗口退出，再次进入时设置回滚为修改前状态；
  - 点击「保存并退出」：配置自动写入保存，选项窗口退出，再次进入确认修改已持久化。
