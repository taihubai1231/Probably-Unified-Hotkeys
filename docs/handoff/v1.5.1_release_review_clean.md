# 可能是按键统一优化 (Probably Unified Hotkeys)

《深空当铺》（*Probably Stolen*）的原版与创意工坊模组设置整合模组。沿用游戏原版 UI 样式，将分散在各处的模组快捷键与常规设置统一纳入官方 `ESC → 选项` 页面，支持组合键、鼠标右键/侧键绑定、空键解绑与多音字检索，并对选项页面、模组封面加载及退出游戏速度进行了优化。

## 功能概览

- 提供三种显示形态：支持模组界面合并至原版界面、模组独立界面在原版选项页左下角放置模组设置入口，以及切换为原版设置界面仅从改造件页面齿轮打开模组配置。
- 原版设置位于上方，创意工坊模组配置默认按拼音首字母排列于下方；各分区均支持独立折叠与恢复默认设置。
- 按住模组卡片右侧拖动手柄即可上下移动卡片，提供按名称升序、按名称降序、自由拖动排列、最近启用优先、按键数量优先与游戏加载顺序 6 种排序方式，排布顺序随预设方案保存且不受恢复默认影响。
- 支持 Shift / Ctrl / Alt 组合键、鼠标右键/中键/侧键绑定及空键解绑；触发组合键时自动屏蔽同名单键，避免误触。
- 支持简繁中文、英文、多音字及拼音全拼/首字母检索；点击 `[!]` 可筛选出全部冲突键位集中修改。

- 在改造件齿轮页与本模组卡片内划分 7 大设置分区，支持单独调整工具栏各项控件显隐、打字停顿响应延时、按键录入与冲突规则、界面语言及各项加速开关，所有设置即时生效。
- 自动汉化常见模组的英文分类与配置项名称；支持将特殊配置项手动设为按键绑定，并提供「模组排查」复制汇总信息以便反馈适配。
- 优化选项页面打开速度，改造件页面优先读取本地模组封面并补充云端封面缓存，缩短返回主菜单与退出游戏的等待时间。

## 使用说明

1. 按 `ESC` 打开「选项」，若选用模组独立界面则点击原版选项页左下角「模组设置」入口；点击目标按键槽后直接按下新按键、组合键或鼠标右键/中键/侧键即可完成绑定；录制状态下按 `Esc` 可清空为「无」，单击鼠标左键则取消本次录入并保留原键位。
2. 修改完成后点击窗口底部的「应用」保存生效。未保存直接关闭窗口时，系统会弹出确认框提示保存或放弃修改。
3. 按住卡片右侧拖动手柄可上下移动卡片，也可在顶栏下拉框切换排序方式；展开本模组卡片，可通过「方案一 / 方案二 / 方案三」保存或读取不同键位与卡片顺序方案，也可通过「导出剪贴板 / 导入剪贴板」跨设备迁移配置。
4. 遇到未走官方配置接口的第三方模组时，可点击选项页顶部的「模组排查」→「复制排查汇总」，将信息反馈给开发者以便跟进适配。

模组越装越多，改键入口却散落各处？空键、组合键与鼠标右键/侧键无法绑定？按键冲突难排查？打开「改造件」页面、返回主菜单、退出游戏都时常卡一下？换电脑或重装游戏后，几十个快捷键和模组设置还要挨个重新调？
